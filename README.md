# NACA-Airfoil-Gen-With-Lift-and-Drag-Equations
Generates airfoils from NACA 4 digit codes, provides lift and drag estimations using Thin Airfoil Theory and Drag Polar Model

# HOW TO USE IT:
1. Enter a 4 digit NACA airfoil code (eg. 2412 or 0012)
2. Your airfoil will be generated on a graph, along with Lift Coefficient, Drag Estimation and Lift-Drag Ratio along various angles-of-attack

# IMPORTANT NOTE:
Lift and Drag are ESTIMATIONS based on the mean camber line. They are relatively accurate when:
- Last two digits(thickness) are between 06 to 12
- First digit(camber) is between 0 - 4
- Second digit(camber position) is 4 - 5
